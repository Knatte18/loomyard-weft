# Raddle shows each part's recipe and profile as table columns

`raddle-table-recipe-profile` · Task · enhancement, stencil, shed · running · Worktree-Create

## Seen (2026-11-11, raddle of gate-scope-by-coverage-map)

Raddle shows its proposed parts to the operator in a table, but states each part's recipe and profile only in the free text around it.
The operator has to read the prose to learn what each part will run as.

## Idea

Give the proposal table one column for the recipe and one for the profile of each part, such as `darn` and `solid`.
The prose keeps only the reasons for the choice and the alternatives set aside.

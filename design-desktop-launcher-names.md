# Desktop launchers are named "lym: <hub>" instead of "lym: start the hub <hub>"

`desktop-launcher-names` · Task · enhancement, desktop · starting · Worktree-Create

## Wish (operator, 2026-11-26)

The desktop launchers `internal/desktoplauncher` writes carry names such as "lym: start the hub odd", which is too long; the operator needs mainly the repository's name.
For now each hub's launcher is named "lym: <shortname>", such as "lym: odd".
Later, with a lym icon on the launcher, the name may be the shortname alone.

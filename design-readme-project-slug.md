# README shows each project's slug

`readme-project-slug` · Task · enhancement, board · running · Drift-Baseline

## Seen (operator, 2026-10-30)

The README's section for a project shows its handle and title but not its slug, so the reader cannot tell which slug to name in a command.

## Design (operator, 2026-10-30)

- Each project section in the README shows the project's slug beside its handle and title, for instance in the section heading.
- A project page shows the slug too, if it does not already.
- Nothing else in the rendering changes.

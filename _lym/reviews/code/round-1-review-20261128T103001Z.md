### [MEDIUM] A remote name git could not resolve reads as a missing path

**Location:** `internal/gitexec/transport.go#namesMissingLocalPath`
**Issue:** With real git 2.53.0, `git push origin` with no `origin` remote, and `git push orgin`, both print `fatal: '<name>' does not appear to be a git repository`.
The capture is the bare remote name.
It is relative, so it is joined to Dir and stat-ed, found missing, and the failure counts as transport.
A misconfigured remote, which no retry fixes, then takes the owed-push route that `PATTERN-pair-remote` retries quietly, or makes a reconcile report Unreachable.
That contradicts the change's own rule that a misconfigured remote stays a refusal.
No test row pins this case either way.

### [MEDIUM] An Add test left on a missing origin now waits out real backoff

**Location:** `internal/fabricengine/add_rollback_adopt_test.go:269`
**Issue:** `TestAdd_GitFailureCarriesGitsOwnReason` points origin at `no-such-remote.git`, which does not exist, and calls `Add` with `AddOptions{}`.
The probe's failure is now a transport failure.
`RetryOriginReadInTransit` (`internal/fabricengine/add.go:89`) therefore retries it after `time.Sleep` of 1 s, 2 s and 4 s (`add.go:81`).
That breaks `PATTERN-test-speed`'s clock rule, and the test now covers the retry path instead of the refusal its comment describes.
The diff moved every sibling fixture of this kind to an existing directory and missed this one.

### [LOW] A dangling symlink origin stays a refusal

**Location:** `internal/gitexec/transport.go#namesMissingLocalPath`
**Issue:** git follows a symlinked origin; a probe with `link.git` pointing at a missing target printed the `does not appear` line naming `link.git`.
`os.Lstat` finds the link itself, so the failure stays a refusal.
A symlink to an unmounted share is one form of the unmounted directory the doc comment and the entry name as unreachable.

### [LOW] An apostrophe or a leading tilde misreads the path

**Location:** `internal/gitexec/transport.go:84`
**Issue:** For `.../it's.git`, git prints the whole path between quotes.
`[^']+` cannot cross the inner apostrophe, so the leftmost match captures `s.git`, which is joined to Dir and found missing.
If `it's.git` exists and holds no repository, the failure is wrongly a transport failure.
A `~/x` URL is printed unexpanded and joined as `Dir/~/x`, always missing, though git reads `$HOME/x`.

### [LOW] A relative path is read against the wrong directory under -C or a subdirectory

**Location:** `internal/gitexec/transport.go:85`
**Issue:** `GitError.Dir` is the process cwd.
git resolves a relative remote URL against the `-C` operand when one is given, and a push run from `r/sub` with `../bare` succeeded, so git read it against the worktree top.
No production caller runs a remote command with `-C` today, and lym runs git at worktree roots, so the effect is small.

### [LOW] The blast radius names less than the change reaches

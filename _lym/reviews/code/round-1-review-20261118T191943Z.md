### [BLOCKING] Import flags named evidence instead of copying it

**Location:** internal/boardengine/intake.go:206

**Issue:** The board entry's first goal bullet reads: "When the board imports an entry from an issue, copy the evidence the issue names into the entry, or into a file the entry references that outlives the source worktree."
The diff copies nothing at import.
`issueContent` adds a note listing the `.lym/` paths, and `importIssue` returns them as `LocalPaths`.
The durable copy moves to filing time through `lym selfreport create --attach`, which the entry's third bullet only asks to consider.
`_lym/landing/summary.md` records this as the writer's own design decision: a `.lym/` path is relative to an unknown worktree on an unknown machine.
That reasoning is sound, but the decision record holds no `Added after Discussion` entry or recorded decision that licenses it, and the focus directive asks whether this gap is a scope finding.
It is: the change the entry asks for is not made.
The fixer cannot settle whether a flag replaces a copy, so the finding is a `decision` for the parent.
It is BLOCKING because this bullet is the task's headline, and landing it unbuilt and unrecorded closes the entry without doing what it asks.

**Location:** internal/boardengine/intake_test.go:166

### [LOW] Path pattern misses common spellings

**Location:** internal/boardengine/intake.go:158

**Issue:** The pattern opens a path only at the start of text or after a character in `pathStopChars`.
`**.lym/x**`, `*.lym/x*`, `path=.lym/x` and `files:.lym/x` match nothing.
The `.lym/` component must be slash-separated, so `C:\wt\.lym\shuttle\x` matches nothing.
lym runs on Windows (`PATTERN-lym-files` names a Windows temp root), so an agent there can write a native path.
The checks I ran against the focus directive's other cases hold: a fenced or markdown-linked path matches, `foo.lym/` and `_lym/` do not, and trailing sentence punctuation is trimmed.

### [LOW] Bare directory mention reported as a file

**Location:** internal/boardengine/intake.go:169

**Issue:** The pattern's tail `[^…]*` may be empty, so `` `.lym/` `` in prose yields the path `.lym/`.
The import note then lists `` `.lym/` `` among the files that did not reach the board, and `local_paths` carries it.

# KDE Plasma 6 window placement

Every batch was already recorded `done` when this session started, so it forked no implementer.
`lym webster status` confirms each batch as `done`, with a digest, no recovery and terminal state.

The batches, with the scope the plan gives them (the plan's intent, not a report of what was built):

- Batch 01 (`kwin-probes`): the KWin probes and recordings, the `beam.window_placement` setting,
  the desktop placement keys and the cancellable window command.
- Batch 05 (`konsole-separate-launch`): the separate Konsole launch and `internal/kwinplace`'s scripts, readers,
  pre-launch checks, script runner, remembered places and planner.
- Batch 11 (`kwinplace-place-flow`): the placement flow, the detached `lym reed place-window` child,
  and the hand-off from `lym reed window` and `lym machine start`.

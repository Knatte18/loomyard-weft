- **MEDIUM** — Card 12 / D4 "a cancelled detached run stops its fixer": the cancel row can't reach the lease path, and the exit it expects is undefined. The card says a passed lease or a signal ends the context during the fixer phase, and the run then returns "the abandoned exit `runRequest`'s cancel rules give". That row would pass even if a lapsed lease left the fixer running, so it cannot fail when D4's cancel branch is broken. The card should name the watcher for the fixer phase, the exit it returns, and a row that lapses the lease file.

## Names of the tooling

A repository file you add or change names nothing of the tooling that runs this session which the repository itself does not already hold: not LoomYard or lym, the board or a board entry, the task, the Sketch or the decision record, the parent or an orch, the scoper, a gate, a tier or a perch.
State the requirement or the decision itself.
The run's own records under `_lym` are outside this rule.

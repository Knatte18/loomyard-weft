# Board README marks projects that have a beam

`readme-beam-marker` · Note · enhancement, board

## What was seen (operator, 2026-11-22)

The rendered board README does not show which projects have a beam, a long-lived pair that spawns its members from its own worktree.

## Idea

Mark each project that has a beam, in its heading and in any project list, so a reader sees at once which projects run as beams.

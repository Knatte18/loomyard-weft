# Reed navigation keys, Alt+arrows, are seeded by lym

`reed-alt-arrow-keys-seeded` · Note · enhancement, reed, config

## Seen

In the loomyard hub opened as a VS Code workspace, Alt+arrow keys do not switch windows and sessions in Reed, which they should.

## Idea

Lym seeds the Reed navigation keys itself, at startup, init or clone, so they work in any hub without manual setup.
Which layer swallows the keys here (VS Code terminal, tmux or the desktop) is not yet known and is the first thing to find.

# Board README drops the Notes level above the type groups

`readme-flatten-note-groups` · Note · enhancement, board

## What was seen (operator, 2026-11-22)

The board README groups features, bugs and enhancements under a Notes heading, as subsections.
Every reader knows those are notes, so the extra level adds nothing.

## Idea

Drop the Notes level: render Features, Bugs, Enhancements and the other type groups as sections of their own.

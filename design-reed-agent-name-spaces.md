# Reed agent button refuses a name with spaces without saying why

`reed-agent-name-spaces` · Note · bug, reed

## Seen (operator, 2026-11-27)

The operator tried the agent button in reed's status bar for the first time and typed a name with spaces.
It was refused without telling the operator what a valid name is.

## Idea

Say what the name allows when asking for it, and on a refusal name the rule and ask again; or turn spaces into dashes.

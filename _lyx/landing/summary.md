# Shortcuts are short forms only; remove lyx attach, pause, resume, start

The top-level shortcuts are now short forms only.
`lyx a` (`lyx reed attach`), `lyx prime` (`lyx orch start`, then `lyx reed attach`), `lyx p` (`lyx tender pause`) and `lyx r` (`lyx tender resume`) stay.
The long forms `lyx attach`, `lyx pause` and `lyx resume` are removed from `internal/shortcutcli/shortcuts.yaml`.
The bare root alias `lyx start` is removed with `loomcli.StartAliasCommand`, its registration in `cmd/lyx/main.go`, the root help's module list entry and the sandbox coverage allowlist row; `lyx loom start` keeps its flags and behavior.

## What changes for callers

Every refusal, notice and envelope line that named a removed form names the full command instead:

- the pause hold line and the covered-run refusal in `internal/pauserecord` name `lyx tender resume` and `lyx tender resume <slug>`;
- tender's hub-entry refusal, the agent-caller refusal and the tender help text name `lyx tender pause` and `lyx tender resume`, and the help names `lyx p` and `lyx r` as the shortcuts;
- the hibernate wake notices, the origin reconcile's parked-push way forward, and `lyx adopt`'s done-task refusal and pause-standing line name `lyx tender resume`;
- a bare `lyx loom pause` refuses naming `lyx tender pause <slug>`.

Package docs, `README.md`, `docs/overview.md`, `docs/skills.md` and the sandbox core suite follow.
The operator command index is generated by the binary, so it drops the removed shortcuts by itself.

## Tests

- The shipped-file row of the shortcut mount test pins the exact set `a`, `prime`, `p`, `r`, and the root help and operator index tests read the surviving shortcuts.
- The root tree test now refuses a bare `start` child beside the retired `run` one.
- The loom start verb test pins `--parent` and the hidden `--no-attach` on `lyx loom start` alone.
- Tests that asserted the old message text assert the new text.

## Design decisions

- Messages name the full command, `lyx tender resume` or `lyx tender pause`, not the one-letter shortcut: a full command reads as a command in a refusal, greps cleanly, and does not depend on the shortcut file.
- `lyx prime` stays: it duplicates no other shortcut, and the board entry does not name it.

# Plan-Review round 2 burler: the prior-round reading rule arrives after the focus directive needs it

The focus directive, which instruction 1 says to read first, points at "round 1's BLOCKING finding".
The rule saying not to read prior-round files until the review is saved is in instruction 2, and the sequencing rule says never to preview a later instruction file.
So I read the round-1 fixer report and bouncer verdict while exploring, before I knew that rule existed.
The review file records this in a process note.

If the rule belongs in the round at all, move it into instruction 1 beside the focus directive.
Or the focus directive should state the prior finding itself, so the reviewer never has to open a prior-round file to learn what it means.

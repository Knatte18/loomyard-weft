# Webster run stopped at batch 01 on a policy violation

No batch completed.
Batch 01 (`01-leased-remote-delete`) was begun and forked, and its fork delivered a report.
`lyx webster record-batch 1` then failed the whole-session audit with a fabric-reference violation.
The fork had run several `cd <worktree>/internal/gitrepo && ...` compound commands (greps, `sed -n` reads, and a heredoc appending tests to `deleteremotebranch_integration_test.go`).
The audit reads these as an implementer fork touching the fabric repo directly.

Per the run rules, the violation is not worked around: the batch was not recovered or re-forked, and batches 02–05 were not started.
The batch is left unrecorded; whether the audit flagged a false positive (the `cd` targets are inside the fork's own worktree) is for an operator to judge before resuming with `lyx webster run`.

# Ship the rule: a tapestry-sized note runs as a Motif, then raddle

`motif-before-tapestry` · Task · enhancement, orch, board · running · Describe

## Why (operator, 2026-11-08)

`docs/research/loom/writer-cost-remeasure-2026-11-08/report.md` found the tapestry Plan phase costs about $35 a run, half of it review and fix rounds, while Motif then raddle splits a large change before any plan, as the fabricengine rewrite did into 11 darns.
The operator's rule: a board note weighed for a tapestry run runs as a Motif first, and raddle then splits its Sketch; raddle chooses each part's shape, tapestry included, and that choice stands.
The rule belongs to lym, for every hub, not to one hub's heddle entry.

## What

- Write the rule into the shipped instructions an orch or board session follows when it picks a recipe for a board entry: the `ly:board-policy` skill (`plugins/ly/skills/board-policy/SKILL.md`), and the orch role or stencil text wherever it names how a recipe is chosen.
- Bring any shipped sentence that contradicts it in line in the same change, such as text that sends a large change straight to tapestry.
- Raddle's own shape choice is not changed.

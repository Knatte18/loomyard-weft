# The board README shows a task's profile in the Recipe column

`readme-profile-in-recipe-column` · Task · enhancement, board · running · Code-Bouncer

## Seen (operator, 2026-11-01)

The board's rendered README shows a task's profile as a bullet under its title in the Task column, such as `` `profile: light` ``, while the Recipe column holds only `tapestry` or `darn`.
The profile is the lower level of the recipe, so it belongs in the same column.

## Idea

The Recipe column shows recipe and profile together, such as `tapestry · light`, or the recipe alone when the task takes its recipe's default profile; the profile bullet under the title goes.
